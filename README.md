# PerpLedger

Hyperliquid history → Koinly-ready CSV (perp realized PnL, funding, fees, spot trades, deposits, withdrawals). Runs entirely in the browser against Hyperliquid's public info API.

Live: https://swarm-t3.github.io/perpledger/

- `site/` — the static app (index.html, app.js, style.css)
- Payment: 9 USDT/USDC on Arbitrum One, verified on-chain in the browser from the tx hash.
